## 2. Dependency Boundary Enforcement
- `routeit_engine` imports **only** Python standard library modules (`dataclasses`, `fractions`, `hashlib`, `json`, `math`, `enum`, `typing`, `random`). It has **zero** imports of `fastapi`, `pydantic`, `sqlite3`, `sqlalchemy`, `routeit_roads`, or `routeit_reference`.
- `routeit_reference` implements a completely separate calculation path using `fractions.Fraction` for differential verification (`AC-10`).
- `routeit_roads` implements the `RoadOracle` protocol (`EuclideanOracle` and `ProfileGraphOracle`).
- `routeit_traffic` implements time-dependent speed profiles, incident overlays, and the world-truth vs. planner-belief execution simulator.
- `backend` coordinates persistence, immutable snapshots, `shift_activation_ledger`, background worker execution, and REST endpoints.
- `frontend` renders the light-themed enterprise dispatcher UI and communicates strictly via the `/v1` API contract.
